日本の畜産動物はいま

採卵鶏・ブロイラー（肉用鶏）・豚がどれだけ飼育され、屠殺され、 どれほど集約化が進んでいるのかを、政府統計（e-Stat）のデータで可視化しています。 国内のアニマルウェルフェアを考えるための基礎資料です。

掲載している数値は政府統計の確報値です。確定値が未取得・未公表の 年次は、推計で埋めず空欄にしています（グラフは線が途切れ、表は「—」で表示）。 一部の系列は e-Stat API からの自動取得を順次進めています。詳細は データについてをご覧ください。

飼育されている数 — 鶏は人口の2倍以上

毎年2月1日時点で飼育されている数の推移です。灰色の線は日本の総人口。 採卵鶏（種鶏を除く成鶏めす）とブロイラーはそれぞれ1億羽を超え、 合計すると日本の人口の2倍以上の鶏が、常時飼育されています。 豚は頭数が人口よりずっと小さく対比の意味が薄いため、単独のグラフで示します。

母豚 — 繁殖の道具として飼われるメス豚

子取り用めす豚（母豚）は、繰り返し妊娠・出産させるために飼育される豚です。 その多くが、体の向きも変えられない妊娠ストールで飼育されています。 頭数は減っていますが、1頭当たりの生産性（年間離乳頭数）は上がり続けています。

年間の屠殺数 — 1年間に殺される数

1年間に食用として処理（屠殺）される数です。ブロイラーだけで年間7億羽超 —— 日本の人口の約6倍にあたる鶏が、生後およそ50日で出荷されています。 採卵鶏も卵を産む量が落ちる1〜2年で「廃鶏」として処理されます。 種類別の内訳は冒頭の図をご覧ください。年ごとの推移は上の「飼育されている数」 セクションの飼養数の推移と概ね連動します。

集約化 — 1戸当たりの飼養数はこの数十年で数倍に

飼育する農家（経営体）の数は減り続ける一方、動物の数はほぼ減っていません。 つまり1戸当たりの飼養数が急増し、少人数で大量の動物を管理する 集約的（工場式）畜産への移行が進んでいます。単位が異なるため鶏（羽）と 豚（頭）でグラフを分けています。 ※畜産統計に従業員数の系列がないため「1戸（経営体）当たり」で示しています。

労働力当たりの飼養数 — 1人（フルタイム換算）で何頭・何羽を担うか

「1戸当たり」は経営体の数だけを見ているため、共同経営や雇用労働力の増加で 規模が変わらなくても数値が動きうる。そこで農林水産省「営農類型別経営統計」 から実際の自営農業労働時間を取得し、1FTE（フルタイム換算＝年間2,080時間、 週40時間×52週）当たりの飼養頭数・羽数を算出した。データが確認できる 平成22年（2010年）と令和4年（2022年）の比較。

飼育密度 — 統計には表れない「過密」

1羽・1頭当たりの飼育面積（飼育密度）は全国統計が存在しません。 ここでは飼養実態調査などで知られている飼育方式の実態を参考情報として示します。

採卵鶏 — ケージ飼育が9割超

約430〜555cm²/羽

国内の採卵鶏の9割以上はケージ（主にバタリーケージ）で飼育されています。 1羽当たりの面積は一般にB5用紙1枚ほどで、羽を広げることもできません。 （畜産技術協会「採卵鶏の飼養実態アンケート調査」等）

ブロイラー — 1m²に十数羽

約50日で出荷

ブロイラーは出荷直前には1m²当たり十数羽という過密状態になります。 急速に成長するよう品種改良され、生後およそ50日で屠殺されます。 （畜産技術協会「ブロイラーの飼養実態アンケート調査」等）

母豚 — 妊娠ストールが約9割

体の向きも変えられない

妊娠中の母豚の約9割は、方向転換もできない幅約60cmの妊娠ストール （檻）で飼育されています。EUなどでは使用が制限されています。 （日本養豚協会「養豚基礎調査」等）

出典・注記

  • 飼養数・飼養戸数: 農林水産省「畜産統計調査」（各年2月1日現在）。採卵鶏は種鶏を除く成鶏めす羽数。
  • 屠殺数: 農林水産省「畜産物流通調査」（と畜統計・食鳥流通統計、暦年）。
  • 人口: 総務省統計局「人口推計」（各年10月1日現在）。
  • データはいずれも政府統計の総合窓口 e-Stat で公開されているものです。
  • 「1戸当たり」は飼養数を飼養戸数で割った値です（畜産統計に従業員数の統計はありません）。
