日本の畜産動物はいま

1年間に殺される数の内訳

出典: 畜産物流通調査・環境省

ブロイラーだけで年間7億羽を超えます。日本の人口の約6倍にあたる鶏が、 生後およそ50日で出荷されています。採卵鶏も卵を産む量が落ちる1〜2年で 「廃鶏」として処理され、卵を産まない雄のひよこは孵化直後に殺処分されます。

年ごとの推移は、次の「飼育されている数」とおおむね連動します。

飼育されている数

毎年2月1日時点で飼育されている数の推移です。灰色の破線は日本の総人口。 採卵鶏（種鶏を除く成鶏めす）とブロイラーはそれぞれ1億羽を超え、 合計すると日本の人口の2倍以上の鶏が、常時飼育されています。 豚は頭数が人口よりずっと小さく対比の意味が薄いため、単独のグラフで示します。

政府統計にケージフリーの系列がないため、確定値が存在しません

麻布大学の大木茂教授は、この報告書の冒頭で 「基本的数値に関し、専門家間で評価が定まっていないことは、大きな問題である」 と指摘しています。ケージフリーの羽数構成比は、消費者ニーズを把握し、 今後の採卵鶏産業のあり方や政策を検討するうえで基本となる数字だからです。

このサイトでは、農場を1件ずつ積み上げて数えたアニマルライツセンターの調査を主に据えました。 同調査は、ケージフリーの鶏群があると分かっていながら連絡がつかず確認できなかった農場が 31件あるため、1.48%は最低値だとしています。 なお同調査では、各農場が増やす予定と回答した33万295羽を含めると1.74%になります。

母豚 — 繁殖の道具として飼われるメス豚

子取り用めす豚（母豚）は、繰り返し妊娠・出産させるために飼育される豚です。 その多くが、体の向きも変えられない妊娠ストールで飼育されています。 頭数は減っていますが、1頭当たりの生産性（年間離乳頭数）は上がり続けています。

集約化 — 1戸当たりの飼養数はこの数十年で数倍に

飼育する農家（経営体）の数は減り続ける一方、動物の数はほぼ減っていません。 つまり1戸当たりの飼養数が急増し、少人数で大量の動物を管理する 集約的（工場式）畜産への移行が進んでいます。単位が異なるため鶏（羽）と 豚（頭）でグラフを分けています。 なお畜産統計に従業員数の系列がないため、ここでは「1戸（経営体）当たり」で示しています。

労働力当たりの飼養数 — 1人で何頭・何羽を担うか

「1戸当たり」は経営体の数だけを見ているため、共同経営や雇用労働力の増加で 規模が変わらなくても数値が動きえます。そこで農林水産省「営農類型別経営統計」 から実際の自営農業労働時間を取り、1FTE（フルタイム換算＝年間2,080時間、 週40時間×52週）当たりの飼養頭数・羽数を算出しました。 データが確認できる平成22年（2010年）と令和4年（2022年）の比較です。

飼育密度 — 統計には表れない「過密」

1羽・1頭当たりの飼育面積（飼育密度）は全国統計が存在しません。 ここでは飼養実態調査などで知られている飼育方式の実態を、参考情報として示します。

採卵鶏 — バタリーケージが9割超

1羽あたり約449cm²

ケージ飼育の羽数のうち93.9%が、最も狭いバタリーケージです。 1羽当たりの面積は平均448.9cm²で、B5用紙1枚（約468cm²）より狭く、 羽を広げることはできません。

麻布大学「ケージフリー採卵養鶏調査」報告書（2025年、ケージ専業43経営の平均）

ブロイラー — 1m²に十数羽

約50日で出荷

ブロイラーは出荷直前には1m²当たり十数羽という過密状態になります。 急速に成長するよう品種改良され、生後およそ50日で屠殺されます。

畜産技術協会「ブロイラーの飼養実態アンケート調査」等

母豚 — 妊娠ストールが約9割

体の向きも変えられない

妊娠中の母豚の約9割は、方向転換もできない幅約60cmの妊娠ストール （檻）で飼育されています。EUなどでは使用が制限されています。

日本養豚協会「養豚基礎調査」等

出典・注記

  • 飼養数・飼養戸数: 農林水産省「畜産統計調査」（各年2月1日現在）。採卵鶏は種鶏を除く成鶏めす羽数。
  • 屠殺数: 農林水産省「畜産物流通調査」（と畜統計・食鳥流通統計、暦年）。
  • 人口: 総務省統計局「人口推計」（各年10月1日現在）。
  • 労働時間: 農林水産省「営農類型別経営統計」。1FTE = 年間2,080時間で換算。
  • 犬猫の殺処分: 環境省「犬・猫の引取り及び負傷動物の収容状況」（年度）。
  • ケージフリーの割合・飼養スペース: 政府統計に系列が存在しないため、民間・大学の調査による推計です。 アニマルライツセンター「ケージフリー羽数調査」（2025年、調査期間6月1日〜10月12日）、 大木茂「2025年 麻布大学『ケージフリー採卵養鶏調査』報告書」（麻布大学獣医学部動物応用科学科 動物資源経済学研究室、2025年8月）、 World Egg Organization。分母の採卵鶏羽数は畜産統計（2024年）です。
  • 「1戸当たり」は飼養数を飼養戸数で割った値です（畜産統計に従業員数の統計はありません）。
  • ブロイラーの統計は2011年に調査対象基準が変わっており、それ以前の年次とは単純比較できません。

データはすべて政府統計の総合窓口 e-Stat で公開されているものです。 ソースコードと元データ: github.com/A-Watahiki/e-stat_animal-welfare
