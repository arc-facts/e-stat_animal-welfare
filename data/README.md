# データについて

このディレクトリの CSV がサイトの元データです。`scripts/build_site_data.py` が
これらを結合・加工して `docs/data/data.json` を生成します。

## ⚠️ 暫定シードデータについて

リポジトリに最初からコミットされている値は、農林水産省・総務省の公表資料
（プレスリリース、概況資料、報道資料）から手作業で整理した**暫定値**です。
グラフの傾向を示す目的には十分ですが、一部の年次は概数を含みます。

`ESTAT_APP_ID`（e-Stat API の利用登録キー）を設定して
`python scripts/fetch_estat.py` を実行すると、e-Stat API から取得した
確定値で CSV が上書きされ、`meta.json` の `provisional` が `false` になります。
GitHub Actions（`.github/workflows/update-data.yml`）でも同じ処理が動きます。

確認済みのアンカー値（2024年7月時点で公表資料と照合済み）:

- 採卵鶏 成鶏めす飼養羽数（種鶏を除く）2024年: 1億2,973万羽、飼養戸数 1,640戸
- 豚 飼養頭数 2024年: 879万8千頭（うち子取り用めす豚 75万8,300頭）、2023年: 895万6千頭・3,370戸
- ブロイラー処理羽数 2023年: 7億4,563万6千羽、2022年: 7億3,721万7千羽
- 廃鶏（採卵鶏など成鶏）処理羽数 2023年: 7,491万6千羽、2022年: 8,330万4千羽

## ファイルと列

### livestock.csv — 飼養数（毎年2月1日現在、全国）

出典: 農林水産省「畜産統計調査」

| 列 | 内容 | 単位 |
|---|---|---|
| `layers_thousand` | 採卵鶏の成鶏めす飼養羽数（**種鶏を除く**） | 千羽 |
| `layer_farms` | 採卵鶏の飼養戸数 | 戸 |
| `broilers_thousand` | ブロイラー（肉用若鶏）飼養羽数 | 千羽 |
| `broiler_farms` | ブロイラー飼養戸数 | 戸 |
| `pigs_thousand` | 豚の飼養頭数（総数） | 千頭 |
| `sows_thousand` | うち子取り用めす豚（母豚）の頭数 | 千頭 |
| `pig_farms` | 豚の飼養戸数 | 戸 |

注: ブロイラーの調査対象は2011年に「年間出荷羽数3,000羽以上」へ変更されて
おり、それ以前と単純比較できない年があります。また農林業センサス実施年
（2010・2015・2020年など）は一部項目が調査休止・組替えの場合があります。

### slaughter.csv — 年間の屠殺数（暦年、全国）

出典: 農林水産省「畜産物流通調査」（と畜統計・食鳥流通統計）

| 列 | 内容 | 単位 |
|---|---|---|
| `broilers_slaughtered_thousand` | ブロイラー（肉用若鶏）処理羽数 | 千羽 |
| `layers_culled_thousand` | 廃鶏（採卵鶏など成鶏）処理羽数 | 千羽 |
| `pigs_slaughtered_thousand` | 豚のと畜頭数 | 千頭 |

### population.csv — 日本の総人口（各年10月1日現在）

出典: 総務省統計局「人口推計」

| 列 | 内容 | 単位 |
|---|---|---|
| `population_thousand` | 総人口 | 千人 |

## 「1従業員当たりの頭数」と「飼育密度」について

- 畜産統計には**従業員数**の系列がないため、サイトでは「1戸（経営体）当たり
  の飼養数」を集約化の指標として掲載しています（`*_farms` 列から算出）。
- **飼育密度**（面積当たりの頭羽数）も全国統計が存在しないため、サイトでは
  畜産技術協会の飼養実態調査等で知られる飼育方式の実態（ケージ飼育率・
  妊娠ストール使用率など）を参考情報として掲載しています。
