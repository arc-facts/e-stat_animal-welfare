# データについて

このディレクトリの CSV がサイトの元データです。`scripts/build_site_data.py` が
これらを結合・加工して `docs/data/data.json` を生成します。

## 掲載方針: 確報値のみ・不明な年は空欄

このサイトは政府統計の**確報値のみ**を掲載します。確定値が未取得・未公表の
年次は、推計や概数で補完せず**空欄**にしています（グラフは線が途切れ、表は
「—」で表示されます）。

大半の系列は `scripts/fetch_estat.py` が e-Stat API の**確報累年統計**から
取得した値です（`ESTAT_APP_ID` を設定して実行、または GitHub Actions
`update-data.yml` が定期実行）。API から未取得の系列・年次は、公表資料と
照合済みの確定値のみを手動で収録しています。`meta.json` の `provisional` は
API 未取得の系列が残っている間 `true` になりますが、**表示される値はすべて
確報値**です。

確認済みのアンカー値（公表資料と照合済み）:

- 採卵鶏 成鶏めす飼養羽数（種鶏を除く）2024年: 1億2,973万羽、飼養戸数 1,640戸
- 豚 飼養頭数 2024年: 879万8千頭（うち子取り用めす豚 75万8,300頭）、2023年: 895万6千頭・3,370戸
- ブロイラー処理羽数 2023年: 7億4,563万6千羽、2022年: 7億3,721万7千羽
- 廃鶏（採卵鶏など成鶏）処理羽数 2023年: 7,491万6千羽、2022年: 8,330万4千羽

## ファイルと列

### livestock.csv — 飼養数（毎年2月1日現在、全国）

出典: 農林水産省「畜産統計調査」

| 列 | 内容 | 単位 |
|---|---|---|
| `layers_thousand` | 採卵鶏の成鶏めす飼養羽数（**種鶏を除く**） | 千羽 |
| `layer_farms` | 採卵鶏の飼養戸数 | 戸 |
| `broilers_thousand` | ブロイラー（肉用若鶏）飼養羽数 | 千羽 |
| `broiler_farms` | ブロイラー飼養戸数 | 戸 |
| `pigs_thousand` | 豚の飼養頭数（総数） | 千頭 |
| `sows_thousand` | うち子取り用めす豚（母豚）の頭数 | 千頭 |
| `pig_farms` | 豚の飼養戸数 | 戸 |

注: ブロイラーの調査対象は2011年に「年間出荷羽数3,000羽以上」へ変更されて
おり、それ以前と単純比較できない年があります。また農林業センサス実施年
（2010・2015・2020年など）は一部項目が調査休止・組替えの場合があります。

### slaughter.csv — 年間の屠殺数（暦年、全国）

出典: 農林水産省「畜産物流通調査」（と畜統計・食鳥流通統計）

| 列 | 内容 | 単位 |
|---|---|---|
| `broilers_slaughtered_thousand` | ブロイラー（肉用若鶏）処理羽数 | 千羽 |
| `layers_culled_thousand` | 廃鶏（採卵鶏など成鶏）処理羽数 | 千羽 |
| `pigs_slaughtered_thousand` | 豚のと畜頭数 | 千頭 |

### population.csv — 日本の総人口（各年10月1日現在）

出典: 総務省統計局「人口推計」

| 列 | 内容 | 単位 |
|---|---|---|
| `population_thousand` | 総人口 | 千人 |

### euthanasia.csv — 犬猫の殺処分数（各年度、全国）

出典: 環境省「犬・猫の引取り及び負傷動物の収容状況」。年度（4月〜翌3月）集計。

| 列 | 内容 | 単位 |
|---|---|---|
| `dogs` | 犬の殺処分数（判明年のみ） | 頭 |
| `cats` | 猫の殺処分数（判明年のみ） | 頭 |
| `total` | 犬猫合計の殺処分数 | 頭 |

注: 畜産の屠殺数（暦年）とは集計期間が異なります（こちらは年度）。この系列は
畜産動物の屠殺数と桁違いに小さいことを示す対比目的で掲載しています。近年の
確認済み値: 2022年度 11,906頭（犬2,434・猫9,472）、2023年度 9,017頭
（犬2,118・猫6,899、過去最少）。それ以前の年は合計値のみ収録しています。

### cagefree.csv — ケージフリー（非ケージ）飼育の割合

**政府統計ではありません。** 農林水産省の畜産統計にはケージフリーの飼養羽数の
系列が存在しないため、民間・大学の調査による推計を、出典ごとにそのまま並べて
収録しています（どれか1つの値に寄せていません）。サイト上でも「推計であること」
「出典によって数え方が違うこと」を明示しています。

| 列 | 内容 |
|---|---|
| `source` | `arc`（アニマルライツセンター）/ `azabu`（麻布大学 大木茂）/ `weo`（World Egg Organization） |
| `year` | 調査・参照年 |
| `scope` | `national`（全国推計）/ `sample`（調査回答内の比率） |
| `cagefree_birds` | ケージフリーの羽数（判明分のみ） |
| `total_birds` | 分母の羽数（判明分のみ） |
| `share_pct` | 割合（%） |
| `note` | 数え方と留意点。サイトの表にそのまま表示される |

サイトの升目図は、`scope` が `national` で羽数が判明している最新の推計（現状は
ARC 2025年）を主として描きます。「他の推計ではこのあたりまで」の淡い範囲は
**出典ごとの最新値**の最大値を使います（WEO の 2022年 5.9% のように、その出典
自身が後年に更新している古い値は範囲の上限に使いません）。

確認済みの値:

- ARC 2025年調査（調査期間 2025年6月1日〜10月12日、2025年11月6日公表）:
  ケージフリー 1,924,435羽 / 129,729,000羽 = 1.483%。連絡がつかず確認できなかった
  農場が31件あるため**最低値**。増やす予定の33万295羽を含めると1.738%。
- ARC 2023年調査: 1.11%（ケージ飼育 98.89%）
- 麻布大学 大木茂「2025年 麻布大学『ケージフリー採卵養鶏調査』報告書」（2025年8月）:
  回答138経営内で 896,410羽 / 28,261,650羽 = 3.17%。成鶏羽数の捕捉率は21.8%で、
  報告書自身が「現実のケージフリー比率よりも高めに出ている可能性がある」と注記。
  同報告書は、この比率を全国の成鶏羽数に当てはめた場合の試算として約410万羽を挙げている。
- WEO: 2024年発表（2023年）3.5%、2023年発表（2022年）5.9%

### cagefree_world.csv — 各国のケージフリー割合

**政府統計ではありません。** 出典は Our World in Data のデータセット
「Share of egg-laying hens in cage-free systems」（CC BY）。各国の最新年の値のみを
収録しています。

| 列 | 内容 |
|---|---|
| `country` | 国名（日本語） |
| `code` | ISO3コード |
| `year` | その国の最新年（**国によって異なります**） |
| `share_pct` | ケージフリー割合（%、羽数ベース） |
| `source` | `owid` / `arc` |
| `show` | 既定のグラフに出すかどうか（`1` で表示）。表ビューには全件を出す |

日本だけは、サイト内の他の項目と数字を揃えるため **ARC の2025年調査（1.5%）を
採用**しています。OWID のデータセット上の日本の値（5.4%・2018年）も
`show=0` の行として残してあります。表示する国は、100%から0%までの幅が
分かるように選んだもので、恣意を避けるため表ビューでは全件を開示しています。

### sow_cycle.csv — 母豚の繁殖サイクル

出典: 広岡博之「ブタの繁殖肥育一貫生産に関するシミュレーションモデルの開発」
日本畜産学会報 89(4): 415-421, 2018 の表1（生産現場への聞き取りをもとにした
ベース条件）。`parameter` / `value` / `unit` / `label` の4列。

サイトの「母豚の一生」の帯は、この値から組み立てています。淘汰される日齢は
同論文の式(1) `初回交配日齢 + 妊娠期間 + (繁殖サイクル数 - 1) × 分娩間隔 + 授乳期間`
＝ 1,170日として `build_site_data.py` が計算します。

**注意:** この論文は生産性と収益を予測するモデルであり、**ストールの使用については
述べていません**。サイトの図で妊娠期間・授乳期間に「妊娠ストール」「分娩ストール」の
名を添えているのは、論文の期間区分に日本での一般的な飼い方を重ねたものです。
図の下の折りたたみでその旨を明示しています。

## 「1従業員当たりの頭数」と「飼育密度」について

- 畜産統計には**従業員数**の系列がないため、サイトでは「1戸（経営体）当たり
  の飼養数」を集約化の指標として掲載しています（`*_farms` 列から算出）。
- **飼育密度**（面積当たりの頭羽数）も全国統計が存在しないため、サイトでは
  飼養実態調査等で知られる飼育方式の実態（ケージ飼育率・妊娠ストール使用率など）を
  参考情報として掲載しています。採卵鶏の1羽当たり飼養面積は、麻布大学の2025年調査に
  よるバタリーケージ平均 448.9cm²（ケージ専業43経営の平均）を採用しています
  （同調査ではケージ飼育羽数の93.9%がバタリーケージ）。
